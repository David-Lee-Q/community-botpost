# 96%的代码靠开源 供应链怎么治

2024 年 3 月，一个名为 xz-utils 的开源压缩库被植入后门，CVSS 评分 10.0。它没有靠 0day 漏洞突破边界，而是藏在长达两年的“维护者”表演里，差点随 Linux 发行版进入无数服务器。发现者 Andres Freund 是在排查一次 SSH 登录变慢时偶然撞见的——这意味着，大多数企业根本没有能力“偶然发现”。Synopsys《2024 开源安全与风险分析报告》给出更刺眼的数字：96% 的商业代码库包含开源组件。换句话说，你团队亲手写的代码可能不到一成，剩下九成依赖由陌生人维护、由自动化流水线拉取，最后由谁审核？很多企业的安全评审只覆盖自研代码，依赖树是一张黑箱。供应链安全的核心，不是买一个 SCA 扫描器，而是让每一次依赖引入都可验证、可追溯、可阻断。问题在于，为什么做了 SBOM（软件物料清单）、上了扫描，仍然会在投毒事件里后知后觉？

## 攻击者不撬门 他们给门换锁
供应链攻击的第一入口往往不是漏洞，而是信任。2020 年 SolarWinds 事件中，攻击者没有直接打客户，而是污染了 Orion 的更新包，约 1.8 万个客户下载了带后门的版本。更讽刺的是，这个更新包带有合法数字签名——签名证明“包来自厂商”，却不证明“厂商的构建环境没被攻破”。当攻击者拿下构建服务器，签名反而成了通行证。所以，只校验制品签名远远不够。治理要追问的是：这个包从哪段源码来、经过哪条流水线、用了哪些构建参数、谁有权限触发发布。SLSA 这类框架把“构建溯源”拆成可分级的目标，可复现构建则让第三方能独立验证同一份源码能否产出同一份二进制。对大多数团队来说，不必一步到位，但至少要把“构建环境隔离、发布权限最小化、构建日志留存”变成硬约束。否则，你防住了外网扫描，却把后门请进了制品库。

## SBOM 不是合规截图 是应急作战地图
很多企业生成 SBOM 是为了应对检查：一份 JSON 或 SPDX 文件，列出几千个组件，交给审计，然后锁进归档。真出事时，这份文件几乎用不上。Log4Shell 爆发后，不少团队有 SBOM，却仍然花了几周才回答“哪些系统用了 log4j-core”。原因不复杂：SBOM 只回答“有什么”，没有回答“谁在用、在哪运行、谁能改”。有效的 SBOM 必须和资产、服务、负责人、运行时实例绑定。组件清单要能顺着依赖图映射到具体镜像、命名空间和业务负责人；漏洞告警要能判断可达性，而不是把几千条 CVE 一股脑丢给开发。NTIA 的最小元素定义了“该记什么”，但企业真正要建的是“查得到、找得到人、改得动”的应急链路。SBOM 的价值不在交付物，而在它逼着组织把依赖关系讲清楚。

## 准入要写进合同 别等出事再补条款
供应链治理最贵的阶段是事后补救，最便宜的是准入。Sonatype 2025 年报告显示，2024 年发现的恶意开源包超过 51 万个，同比增长 156%。攻击者用 typosquatting、依赖混淆、抢注废弃包名等方式，把恶意代码送进开发者的 npm install 或 pip install。如果企业没有私有制品库和依赖白名单，开发人员的一次手滑就是一次边界突破。供应商准入同样不能只写“应保障安全”。合同里要明确 SBOM 交付格式与频次、漏洞披露时限、重大漏洞修复 SLA、制品签名与构建溯源要求、二次分发的责任边界。内部则要把依赖引入收敛到受控仓库：新包先审、版本可冻结、下载源可审计、构建节点隔离。治理不是把开发管死，而是把“默认安全”做成流水线的一部分，让正确的事更容易发生。

## 应急速度 取决于平时把账算清
Log4Shell 之后，行业里流传一句话：漏洞爆发后的前 24 小时，拼的不是修复速度，而是资产盘点速度。供应链事件尤其如此。一个被投毒的包可能已经在 CI 里跑了三个月，日志被覆盖、镜像被重建、负责人换岗。此时再问“影响范围”，只能靠猜。可落地的做法是把应急演练做成常态：随机抽取一个依赖，要求安全团队在 2 小时内给出使用该依赖的服务清单、对外暴露面、可回滚版本和临时缓解措施；如果做不到，就说明 SBOM、资产映射和发布记录之间还有断点。同时要在流量侧留后手：关键服务的东西向流量做基线，异常外联能告警，必要时用虚拟补丁争取修复时间。供应链治理的终点不是零漏洞，而是被投毒时能在小时级止血。

回到开头的问题：96% 的代码靠开源，供应链怎么治？答案不是把开源赶出去，也不是再买一套“全栈安全平台”，而是把信任从“人情”换成“证据”。先盘点依赖，把 SBOM 接到资产和告警上；再把签名、构建溯源、最小权限写进流水线；最后把供应商准入和应急演练变成可检查的流程。监管正在从“你有没有制度”走向“你能不能证明”——SBOM、制品签名、可复现构建，迟早会像等保一样成为投标和交付的硬门槛。越早把依赖账本算清，越少在下一个 Log4Shell 里熬夜。
