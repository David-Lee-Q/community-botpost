# 社区文章质量评价标准

- 版本：v1.0
- 制定日期：2026-08-08
- 适用对象：卡奥斯开源社区（openlab.cosmoplat.com）发布的科技类原创文章（含 bot 自动发文）
- 参考框架：Google E-E-A-T（经验、专业、权威、信任）、内容营销质量维度、开源社区内容规范
- 评分方式：100 分制，按维度加权计分，另有 8 项一票否决红线

## 一、评价维度与权重

| 维度 | 权重 | 考察要点 |
|------|------|----------|
| 内容原创性 | 20% | 原创度、同质化程度、增量价值、AI 痕迹控制 |
| 技术准确性 | 20% | 事实、数据、术语、技术观点的正确性与时效 |
| 完整性结构 | 15% | 主题聚焦、结构清晰、逻辑递进、深度充分 |
| 可读表达 | 15% | 语言流畅、段落节奏、图文配合、术语通俗化 |
| 规范合规 | 15% | 平台规则、格式规范、敏感内容、版权风险 |
| 传播表现 | 15% | 标题吸引力、摘要价值、SEO 友好、互动引导 |

## 二、分档标准

| 档位 | 分数 | 说明 |
|------|------|------|
| 优秀 | 90-100 | 深度原创，数据扎实，结构典范，具备传播潜力 |
| 良好 | 75-89 | 内容充实准确，结构完整，小瑕疵不影响阅读 |
| 合格 | 60-74 | 满足发布底线，存在明显可改进项 |
| 不合格 | <60 | 低于发布门槛，需返工 |

## 三、各维度评分细则

### 1. 内容原创性（20 分）

| 分数 | 标准 |
|------|------|
| 18-20 | 观点或素材有独到增量，非搬运改写，有明确个人/项目实践支撑 |
| 14-17 | 主题常见但组织有特色，数据与案例为原创整理 |
| 10-13 | 综合多方资料成稿，原创成分中等，同质化程度高 |
| 0-9 | 明显拼接搬运，仅词序改写，无增量价值 |

否决红线：整篇抄袭或直接搬运他文超 30%，直接判 0 分并拒绝发布。

### 2. 技术准确性（20 分）

| 分数 | 标准 |
|------|------|
| 18-20 | 术语规范、数据可溯源（注明来源或时间）、观点与主流技术共识一致 |
| 14-17 | 技术表述准确，个别数据陈旧但未失真 |
| 10-13 | 存在 1-2 处表述不准或过时说法 |
| 0-9 | 出现事实错误、概念混淆、过期产品信息 |

加分项：附参考文献、数据来源链接、版本号与时间戳。

### 3. 完整性结构（15 分）

| 分数 | 标准 |
|------|------|
| 13-15 | 引言-分论点-案例-结论层层递进，每部分逻辑自洽 |
| 10-12 | 结构完整但部分章节跳跃或深度不足 |
| 6-9 | 结构松散，论点堆砌，结论缺失 |
| 0-5 | 无结构，流水账式罗列 |

要求：正文 ≥1000 字；每个分论点有论据支撑（数据/案例/引用其一）。

### 4. 可读表达（15 分）

| 分数 | 标准 |
|------|------|
| 13-15 | 语言流畅，每段聚焦一个点，图文呼应，术语有解释 |
| 10-12 | 表达清楚，个别段落冗长或配图无关 |
| 6-9 | 段落过长、口水话多、配图缺失或排版混乱 |
| 0-5 | 语言晦涩、病句多、影响理解 |

要求：每段 ≥200 字且单一主题；正文配图 ≥2 张且与内容相关；配图须免费可商用（magnific.com / Pexels / Unsplash / Pixabay），正文图直接引用图片链接，封面图下载到 `/workspace/bot/covers/<主题>/` 按主题分类后上传，避免多篇混用。

### 5. 规范合规（15 分）

| 分数 | 标准 |
|------|------|
| 13-15 | 标题/摘要/分类/封面/正文全部符合平台规范 |
| 10-12 | 有 1 处轻微不符（如摘要略短、封面比例略偏） |
| 6-9 | 2 处以上格式问题或分类归属不当 |
| 0-5 | 违规内容或多次触碰平台红线 |

硬性要求（不满足直接扣至合格线下）：
- 封面：800×400、jpg/png、≤1MB
- 标题：禁用冒号，不夸张不误导
- 摘要：约 120 字，概括核心价值
- 正文：不得重复标题或二级标题文字；不得含敏感、侵权、广告引流内容

### 6. 传播表现（15 分）

| 分数 | 标准 |
|------|------|
| 13-15 | 标题有信息量有钩子，摘要直击痛点，首段 3 句内抓住读者 |
| 10-12 | 标题准确但平淡，摘要完整但缺少吸引力 |
| 6-9 | 标题含糊或过泛，摘要冗长无重点 |
| 0-5 | 标题党或文不对题，摘要与正文不符 |

## 四、一票否决红线（任一命中即拒绝发布）

1. 全文抄袭或拼接搬运超 30%，无来源说明
2. 存在事实性硬伤或传播虚假信息
3. 含违法、敏感、涉政或不良引导内容
4. 涉及侵权素材（未授权图片、商用字体、受版权保护内容）
5. 文不对题或标题严重误导
6. 含广告、外链引流、营销导流信息
7. 正文未达 1000 字（科普短文类除外，须单列审批）
8. 封面缺失或格式不符无法展示

## 五、发布前自检清单（Checklist）

- [ ] 标题：无冒号、无夸大、含核心关键词，≤30 字
- [ ] 摘要：约 120 字，覆盖"现状-观点-价值"
- [ ] 封面：800×400、≤1MB、与主题相关、无版权风险
- [ ] 正文：≥1000 字、每段 ≥200 字、不重复标题/二级标题文字
- [ ] 配图：≥2 张、出处可商用、与内容对应
- [ ] 分类：归属正确（对照 CATEGORY_IDS 17 个分类）
- [ ] 数据：关键数据标注时间或来源
- [ ] 术语：出现缩写首次给出全称
- [ ] 结论：结尾有明确观点或行动建议

## 六、与自动化的结合

可自动化校验项（由 bot/脚本执行）：
- 字数、段数、段落长度统计
- 封面尺寸与大小检查
- 标题是否含冒号/长度
- 摘要长度
- 配图数量
- 是否重复标题或二级标题文字
- 分类 ID 有效性

需人工判定项：
- 原创度与增量价值
- 技术准确性
- 版权与合规
- 传播吸引力

建议：bot 发布前自动执行"可自动化校验项"，未通过则拦截并告警；人工复核"需人工判定项"后放行。
