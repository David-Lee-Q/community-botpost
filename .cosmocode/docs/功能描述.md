# 功能描述

## 系统定位

面向卡奥斯开源社区（openlab.cosmoplat.com）的自动化内容运营系统。系统以无人值守方式完成科技文章的定时发布、数据采集、质量评价与报告推送，形成「发布 → 评价 → 改进 → 再发布」的运营闭环。

## 功能模块

### 1. 定时自动发文（bot）

- **计划驱动**：以 `bot/plan.json` 为发布计划源，每条计划包含时间、标题、分类、正文文件、摘要、封面图路径
- **到点发布**：守护进程每 30 秒轮询计划，到达计划时间自动调用平台发布接口（`POST /api/article/save`），无需人工干预
- **防重复**：发布前按标题精确查重，同名文章不重复推送
- **详情 URL 记录**：发布成功后从「我的文章」页抓取文章详情页真实地址，写入计划文件与当日发布清单
- **封面自动上传**：封面图按主题归档在工作区，发布时自动上传并关联文章
- **令牌自管理**：登录令牌（JWT）有效期约 7 天，失效后自动通过浏览器重新登录获取

### 2. 发布台账展示页（ledger）

- **数据总览卡片**：历史累计、本月发布、本周发布、今日发布（含图标立体悬浮样式）
- **图表分析**（8 个图表面板，均支持 hover 立体悬浮）：
  - 每日 / 每周 / 每月发布量趋势
  - 分类分布、分类发布趋势（近 6 个月）
  - 文章评价分数趋势（按日 / 周 / 月切换）
  - 浏览次数趋势（按日 / 周 / 月，含同比 / 环比）
  - 互动次数趋势（按日 / 周 / 月，评论 + 点赞 + 收藏）
- **明细查询**：文章列表支持关键词搜索、分类筛选、分页；评价列展示等级与分数（hover 查看评分维度明细）
- **综合评分标签**：页面右上角常驻显示当前综合评分，带呼吸跳动动画，点击查看下周优化建议
- **数据自动刷新**：发布完成后及每 6 小时自动同步平台数据，浏览 / 互动实时增长可见

### 3. 质量评价闭环

- **自动评价**：全量已发布文章按传播表现百分位自动评分（浏览权重 0.7 + 互动权重 0.3），bot 文章人工评价优先，自动评价不覆盖人工结果
- **每周综合评分**：每周一自动计算上一完整周综合分（当前 88 分），基于 6 维度 100 分制评价标准（原创性、准确性、结构、可读、规范、传播），8 项一票否决
- **改进任务沉淀**：评分结果自动同步到改进任务清单与质量改进记录，评分低于 85 分时强制要求下批文章落实改进要点

### 4. 飞书报告推送

- **每日总结**（每日 18:00）：今日发布 / 浏览量 / 互动、当日文章表现表格（标题带超链接直达详情页）、综合评分
- **每周总结**（每周一 10:00）：本周发布 / 浏览量 / 互动、综合评分（按 85 / 70 分档着色：绿 / 橙 / 红）、短板维度、改进建议、下周待发布数
- **卡片样式**：飞书 interactive 卡片，日报蓝色 / 周报绿色头部，文章表现采用表格布局
- **手动能力**：支持 `--preview` 参数仅预览不推送

### 5. 定时任务调度（runner）

守护进程统一调度全部定时任务（每 30 秒轮询）：

| 触发时间 | 任务 |
|----------|------|
| 每 30 秒 | 发布计划轮询 |
| 每日 06:00 | 生成新一批发布计划（扩展点） |
| 每周一 06:00 | 上周综合评分与改进任务沉淀 |
| 每日 0 / 6 / 12 / 18 点 | 台账数据刷新 |
| 每日 18:00 | 飞书每日总结 |
| 每周一 10:00 | 飞书每周总结 |

### 6. 服务启停脚本

- **start.sh**：端口固定 8090；已启动直接返回 0，未启动则后台启动并校验首页可访问，成功返回 0、失败返回 2
- **stop.sh**：基于 `ss` 提取 PID 并停止，等待端口释放；未运行幂等返回 0

## 工作流程

```
新增文章计划(plan.json + 正文 + 封面) → runner 到点发布 → 抓取详情URL
        ↓
台账数据刷新(浏览/互动) → 自动评价
        ↓
台账展示页实时呈现 → 每周综合评分 → 改进任务
        ↓
飞书日报/周报推送 → 改进反馈到下一批文章
```

## 核心约定

- 文章规范：封面 800×400 jpg/png ≤1MB；正文 ≥1000 字、每段 ≥200 字、≥2 张免费可商用配图；标题禁用冒号；需 120 字摘要
- 配图来源：正文图从 magnific.com / Pexels / Unsplash / Pixabay 检索免费图直接引用链接；封面图下载到工作区按主题分类保存（`bot/covers/<主题>/`），避免多篇混用
- 部署：台账展示页静态服务端口 8090，根路径即首页
